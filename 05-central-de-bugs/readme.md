# Central de Bugs 🐞

Um projeto desenvolvido em Python para simular a classificação e o direcionamento de bugs de acordo com o nível de gravidade.

A ideia surgiu enquanto eu estudava estruturas condicionais e queria colocar o conteúdo da aula em prática de uma forma que tivesse relação com uma área que me interessa: **Qualidade de Software e Testes**.

## Como funciona

O sistema apresenta quatro níveis de gravidade e, a partir da escolha do usuário, define uma ação para o bug:

* **1 — Baixa:** Bug registrado com prioridade baixa.
* **2 — Média:** Bug enviado para análise.
* **3 — Alta:** Desenvolvedor deve ser acionado.
* **4 — Crítica:** Prioridade máxima. O bug deve ser tratado imediatamente.

Também existe uma validação para quando o usuário informa uma opção que não está disponível.
