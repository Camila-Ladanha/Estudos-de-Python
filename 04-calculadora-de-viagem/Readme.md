# 🚗 Calculadora de Viagem

Um projeto desenvolvido em Python para praticar conceitos da linguagem através de uma situação simples do dia a dia.

Essa calculadora serve para calcular quanto de combustível será necessário em uma viagem, o custo total e quanto cada pessoa vai pagar.

## O que ela calcula?

* Quantos litros de combustível serão necessários
* O custo total da viagem
* Quanto cada pessoa vai pagar

## 🐍 O que pratiquei

Nesse exercício, pratiquei:

* Variáveis
* Operações matemáticas
* Divisão e multiplicação
* Números decimais
* 'print()'
* 'f-string'
* Formatação com '.2f'

## 💻 Exemplo

'''text
Você precisa de 40.77 litros
A viagem custa R$ 284.16
Cada pessoa vai pagar R$ 142.08
'''
